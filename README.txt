■ 起動方法
1. ZIPを展開します。
2. WindowsでPythonが入っている場合は start_demo.bat をダブルクリックしてください。
   自動的に http://localhost:8000/ を開きます。
3. Pythonを使わない場合は index.html を直接ブラウザで開いても基本動作を確認できます。

Chrome / Edge / Firefox の最新版を推奨します。

  - PDF優先
  - 本文画像優先
  - 閲覧モード自体はPDFが登録されている場合PDFを優先
- 価格を0円に設定すると「¥0」ではなく「無料」と表示

■ PDFレンダリング
【iPadトーン補正（推奨）】
指定倍率でPDFを高解像度Canvasへ描画したあと、最終的な表示物理解像度まで複数段階で縮小します。
1回で大きく縮小するよりスクリーントーンの周期成分を平均化しやすく、干渉縞（モアレ）を軽減する狙いです。

【高精細モード】
指定倍率の高解像度CanvasをそのままCSSで表示領域へフィットします。
iPad版実装後に実機で見え方を比較できるよう残しています。

PDF描画倍率はPDF自体の原稿ピクセル寸法には依存しません。
100%は、その端末でPDFページ全体を表示するために必要な物理解像度を基準にします。
例: 180%ならその約1.8倍で一度描画します。

iPad Pro 11インチではCSSピクセル×devicePixelRatioを使って実際の物理解像度に近い基準で処理します。

■ お品書きの動作
- サークルカード → 登録された頒布物の順にZ字状にフォーカス
- 最後まで行ったら同じ経路を逆に戻ります
- 往復後、同人誌を1冊ずつ自動プレビュー
- 次にまたお品書き往復 → 次の本プレビュー、と繰り返します
- 手動で動かした後は、一定時間放置すると現在位置からサークルカードへ滑らかに戻ります

■ PDFについて
ブラウザ版デモでは、PDFの1ページ表示にPDF.jsを必要に応じてオンライン読み込みします。
PDF.jsを読み込めない環境では、ブラウザ標準のPDF表示へフォールバックします。
最終的なiPad完全オフライン版では、PDF表示ライブラリもアプリ内に同梱する予定です。

■ データ保存
登録した画像・PDFはブラウザのIndexedDB、文字設定はlocalStorageに保存します。
「データ」タブからブランク状態にして、管理画面だけで一から登録できます。

■ 注意
これはUI・動作を調整するためのブラウザ試作です。
スクリーントーンの見え方はPCブラウザとiPad Pro実機で差が出るため、最終的にはiPad実機で「トーン補正」と「高精細」を比較して描画倍率を決める想定です。
